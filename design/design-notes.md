# 设计笔记 · 《乌合之帖》

## 一句话概念

被很多人相信的，不一定是真的——它可能只是被很多人转述过。

## 分幕结构

| 八 | 房间 · 发布编辑器 | 选择回应方式 → 结局 |

## 四条真相线（8 结局）

1. **现状线**：现有材料 → 结局一~四（含糊 / 认错 / 未定 / 共同署名）+ 隐藏结局（完整核对后发布带来源的更正）
2. **黑化线**：登录记录 + 相册回收站 → 裁图与编辑都是自己 → 结局五「认领」
3. **反派线**：EXIF 修改时间 + 胶带新旧 → 完整照片系补拍，白噪音设局 → 结局六「对峙」（给 / 不给原稿双收尾）
4. **罗生门线**：三视角记忆互相矛盾 → 四人联合声明 → 结局七

## 美术规范

- 基调：雾白 `#F4F3EF` / 墨 `#2B2B28` / 蓝灰 `#52677F`（平台色，克制使用）
- 线索五色：记录可确认（青绿）/ 他人陈述（蓝灰）/ 我的推测（暖黄）/ 待核实（灰）/ 来源冲突（赭红）
- 回声 App 为深色夜间模式（知乎风评论区），与雾白现实层用手机框区隔
- 3D 场景：序幕傍晚金色夕照（低角度平行光+落日+体积光），书房深夜（台灯暖光+屏幕冷光）
- 动效：全部缓动函数驱动，相机位移带步行 bob / 呼吸浮动；幕间切换为电影黑场（上下黑边+幕题+过渡句）

## 交互原则

1. 所有操作即时反馈，不整页刷新
2. 私人行为（收藏/笔记）与公开行为（点赞/置顶/发布）严格区分，公开行为全部留痕可回放
3. 线索不直接展示，记入"调查笔记"由玩家主动翻阅
4. 任何结论必须先有证据链：追问→输入中→回复；解锁→内容；检查→回放
