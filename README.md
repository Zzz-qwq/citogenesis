# 乌合之帖

> 一个关于"一句话如何被滚成事实"的第一人称信息解谜游戏。
> 游戏本体是单个 HTML，音频在 `game/assets/audio/` 下（BGM 93s 无缝循环 + 开/关机音效）。
> 无需安装；联网时 Three.js 走 CDN，3D 效果最佳。

## 怎么开始

**在线直接玩（无需安装）：** https://zzz-qwq.github.io/citogenesis/

**演示视频：** https://zzz-qwq.github.io/citogenesis/demo.mp4

或者本地运行：

- 直接双击 `game/index.html` 用浏览器打开（保持 `assets/` 与 HTML 相对位置不变）；
- 或双击 `scripts/open-game.bat`（自动用默认浏览器打开）。

建议 Chrome / Edge。首次进入有前情过渡，点击任意处可跳过并同时开启音乐（浏览器要求首次交互后才允许出声；右上角 ♪ 可静音）。

## 你在玩什么

你是林默。周二你发的一篇帖子被转发了四万次，周三凌晨之后你断片了三天。
周五傍晚你在书桌前醒来——评论 6,391、私信 2、互动消息 99+，都在等你的回应。
拿起手机，弄清楚：那晚到底发生了什么，以及——你要怎么回应。

- **九幕主线**：序幕（傍晚苏醒）→ 帖子 → 照片调查 → 评论区 → 编辑历史 → 私信 → 摘要整理 → 时间线证据板 → 发布回应
- **分歧点**：拼完时间线后，选择你相信的"真相版本"（现状 / 黑化 / 反派 / 罗生门）
- **8 个结局**：4 种回应结局 + 3 个真相线结局 + 1 个隐藏结局（需完成完整核对清单）
- 右上角**调查笔记**会替你记下每一条线索（E01–E11）

## 操作提示

- 所有交互都是即时的：点赞、撤回、追问、折叠，所见即所得
- 手机：锁屏 → 上滑解锁 → 屏幕内上下滑动浏览
- 电脑：走近书桌 → 按电源键 → Windows 桌面 → 照片应用（可缩放/拖拽/看 EXIF）
- 真相线结局页可"回到分歧点"，重走另一条真相

## 技术

- 单个 HTML 文件，零构建；Three.js r128（CDN）负责序幕/书房 3D 场景与光影
- 其余全部为原生 HTML/CSS/JS，存档状态保存在页面生命周期内
